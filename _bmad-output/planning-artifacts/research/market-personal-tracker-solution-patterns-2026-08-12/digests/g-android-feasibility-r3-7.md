## VERDICTS PER TOPIC

- **Notifications** — works, with user-revocable POST_NOTIFICATIONS (A13+); heads-up restricted (channel-importance + system conditions, not forceable; suppressible by OEM battery managers); trampolines restricted (targetSdk 12+ must use direct PendingIntents); non-dismissable ongoing unverified this run; NLS read/suppress unverified this run.
- **Exact alarms / FSI / background launch** — exact alarms restricted + user-revocable (denied-by-default on A14+ for most new targetSdk33+ apps; USE_EXACT_ALARM path for alarm/calendar-class apps); FSI restricted + user-revocable (A14 default-grant only for alarm/call apps; Play revokes otherwise; degraded to heads-up when denied); START_ACTIVITIES_FROM_BACKGROUND impossible for third-party (privileged/signature); alarm-triggered FGS and notification-tap paths work as sanctioned background-launch channels; WorkManager works for deferrable reminders; setAlarmClock works through Doze (but positions the app as an alarm clock under Play scrutiny).
- **App blocking & usage visibility** — usage tracking works but coarse (daily/weekly/monthly/yearly aggregates; not real-time), via user-granted, revocable PACKAGE_USAGE_STATS special access; true blocking of other apps impossible without Accessibility overlay/redirect or Device Admin (mechanism market-standard but user-revocable); Digital Wellbeing app limits: no public third-party API found (absence); the tracker app itself can be Doze/Standby-deferred when rarely used.
- **Voice** — works; RECORD_AUDIO runtime permission + SpeechRecognizer (cloud by default, needs Google app + network); on-device recognition works on API 31+ devices that support it, with availability/quality variance and language-pack dependence; ML Kit on-device alternative.
- **On-device AI / Gemini** — Gemini Nano works but gated: AICore + hardware NPU + OEM-supported build + model download; device coverage flagship-subset; May-2026 "Gemini Intelligence" raises requirements (Android 17, 12GB RAM); cloud Gemini API free tier unverified this run (ai.google.dev unreachable); privacy: on-device keeps data local, cloud sends data to Google.
- **Battery & reliability** — Doze defers standard and even setExact alarms; setAndAllowWhileIdle/setAlarmClock are the sanctioned wake paths (quota-limited); App Standby buckets defer jobs/alarms/network on battery; battery-saver killing FGS unverified this run; BOOT_COMPLETED exists but Android 15 blocks launching several FGS types from it; OEM battery managers are the biggest real-world reliability variable.
