- (decision) Primary home surface: State-Aware Focus & Resumption Hub hero card (active/upcoming/resumable/idle state) with secondary Today Schedule and Action List views below
- (decision) Item Architecture: Unified capture entry point inferring type (with confirmation fallback), mapped to specialized domain models (Tasks, Routines with DayType, Habits with slack, Study Sessions with heatmaps) sharing scheduling, focus, reward, and reminder services
- (decision) DayType Resolution: Hierarchy (date override > calendar exception > day-of-week default). Auto-activates with zero mandatory friction; non-blocking Hero Card banner offers 1-tap single-date swap without mutating base template
- (decision) Focus Interventions: State-Aware Smart Prompting. Schedule prompts start via Hero Card; opening distracting app triggers ONE contextual JITAI prompt. Once FocusSession explicitly starts, AccessibilityService blocking + B ladder activates until completion/exit
- (decision) Notification Model: Soft-Cap Quota Guidance (Routine quiet, Important standard, Urgent high-importance heads-up + audio/haptics). 3rd active Urgent item triggers soft prompt without hard cap. Uses acknowledgement-based escalation
- (decision) Rescheduling & Carry Forward: Item-type aware review (Tasks -> transparent Carry Forward review with actions; Fixed Events -> require re-keying; Routines -> expire without stacking; Habits -> slack recovery). Capacity indicator is advisory only
- (decision) Voice Capture: Confidence-Threshold Routing (High -> immediate + Undo toast; Medium -> confirmation card; Low/Failed -> Unfiled Inbox). Strict AI Action Boundary: model output never directly mutates DB without schema/business rule validation
- (decision) Companion & Coins Scope: Lightweight Cosmetic & Decor Progression only in v1. Coins awarded for genuine completions, spent only on cosmetics. Streak system is architecturally separate from Coins. Real-life reward sinks excluded from v1
- (decision) Security & Backup: Encrypted Local DB at rest + password-protected encrypted manual backup. Raw voice audio discarded post-STT. Zero default cloud sync. Cryptographic implementation details delegated to Architecture phase
- (decision) V1 Exclusions & Non-Goals: Multi-user, cloud sync servers, monetization, punitive gamification, real-life reward sinks, direct AI DB mutation, hard break locks, mandatory cloud AI, and system calendar import excluded from v1. Voice capture, encrypted local storage, manual encrypted backup, and cosmetic companion included in v1
