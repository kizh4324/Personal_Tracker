- (decision) PRD Functional Rule 1: Dual-Trigger Interrupted/Resumable State (FocusSession early exit OR scheduled block expiry with item IN_PROGRESS). Hero Card presents Resumption Card with Resume, Review/Adjust, Mark Complete. Never auto-completes or silently reschedules.
- (decision) PRD Functional Rule 2: System Immunity & State Reconstruction. Emergency calls/telecom bypass blocking. OS kills/reboots reconstruct state into INTERRUPTED/RESUMABLE on next launch. Explicit Cancel sets CANCELLED without resumption prompt.
- (decision) PRD Functional Rule 3: Inline Hero Card Confirmation with 1-Tap Chips for Medium-Confidence capture (explicit Confirm required). Low-confidence entries land in Unfiled Capture Inbox with original transcript for 1-tap categorization.
- (decision) PRD Functional Rule 4: Mid-day DayType swap preserves completed/in-progress items as immutable, recalculating only remaining unstarted schedule for today. Single-date override persisted locally; tomorrow reverts to standard hierarchy.
- (decision) PRD Functional Rule 5: Completion Validation & Anti-Farming model. Reward-event idempotency prevents duplicate Coins on repeated UI toggles. Service-validated completions required. Duration thresholds and Coin amounts are hypotheses.
- (decision) PRD Functional Rule 6: Password Prompt + Transactional Restore Protection for Backup. 4-step validation (password, integrity, format, schema). Pre-restore safety snapshot ensures rollback if restore fails. Portable across devices with password.
