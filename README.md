# Personal Tracker 🚀

Personal Task, Habit, and Routine Tracking Application built with spec-driven architecture and AI agent-assisted development (BMAD Method).

## 📌 Overview

**Personal Tracker** is a production-quality, local-first mobile application designed to solve fragmented daily routines, inconsistent study/learning hours, unstructured free-time distraction, and notification fatigue.

- **Adaptive Routine Tracking:** Separate routines for weekdays, weekends, and college days.
- **In-the-Moment Guidance:** Smart distraction prompts and focus timers.
- **Gamified Progress:** Companion reactions, streak tracking, and micro-rewards.
- **Privacy & Local-First:** 100% free, offline resilient, with local data ownership.
